# Le Ciel '24 Website Components

Frontend web components built with HTML, CSS, and JavaScript for **Le Ciel '24**, the annual cultural festival of NIT Puducherry.

## Components

| File | Description |
| :--- | :--- |
| `index_count.html`, `styles_count.css`, `script_count.js` | Live festival countdown timer displaying remaining days, hours, minutes, and seconds |
| `index_navbar.html`, `styles_navbar.css`, `script_navbar.js` | Responsive festival navigation bar |
| `About Page/` | Festival overview and about section assets |

## Usage

Open `index_count.html` or `index_navbar.html` in any web browser.
